# Elasticsearch 素振りログ

Elasticsearch の基本原理を、プログラミング言語やアーキテクチャを持ち込まずに REST API を直接叩いて確かめる練習の記録。

## 進め方

- 課題ごとに「考えること」「やること」「確認すること」を置く。
- 実際に送ったリクエスト、返ってきたレスポンス、そこから自分で考えたことを課題ファイルに追記していく。
- 答えは先に書かない。結果を見て自分で説明してから答え合わせをする。

## 環境

- Docker イメージ: `elasticsearch:8.15.3`（`mirror.gcr.io/library/elasticsearch:8.15.3` から取得）
- 外部プラグイン配布サーバー（artifacts.elastic.co）には接続できないため、標準で入っている機能だけを使う。
